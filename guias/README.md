# Guías

Material de apoyo que no pertenece a una unidad: herramientas de trabajo que se usan a
lo largo de toda la materia. Las carpetas siguen el orden en que conviene leerlas, y
dentro de cada una el número del archivo es el orden.

Todavía no se revisaron el contenido ni el estilo: vienen de cursadas anteriores y de
otros cursos.

| carpeta | guía | qué cubre |
|---|---|---|
| `01_entornos/` | `01_entornos_python_con_uv` | Entornos virtuales, instalar Python y uv, kernel en VS Code y Jupyter, crear y borrar sin dejar restos |
| `02_git_github/` | `01_repo_de_cursada` | Git y GitHub para organizar el repositorio personal de la cursada: convenciones, flujo diario, entregas, ramas simples |
| | `02_ramas_actions_y_hugging_face` | Git por consola, ramas y conflictos, GitHub Actions, integración con Hugging Face, 5 ejercicios |
| `03_docker/` | `01_entorno_virtual_o_docker` | Cuándo alcanza con un entorno virtual y cuándo conviene un contenedor; estrategia híbrida |
| | `02_docker_con_una_app` | Imagen y contenedor, instalación, comandos, `.env`, Dockerfile, una app de Gradio en contenedor, laboratorio de rotura |
| `04_hugging_face/` | `01_token_de_acceso` | Crear, usar y proteger el token de acceso |
| | `02_publicar_un_space` | Cheatsheet: estructura de un Space, despliegue con Git, Gradio, plantillas |
| `05_automatizacion/` | `01_n8n_con_docker` | Instalar Docker y levantar n8n en un contenedor |
| `consulta/` | `cheatsheet_redes_neuronales_keras` | Capas de Keras, compilación, curvas de aprendizaje, pipelines de HF |
| | `cheatsheet_transformers_llms_stanford.pdf` | CME 295 (Stanford), en español: tokens, embeddings, atención, Transformers, LLMs |

`03_docker/` trae su propio `requirements.txt` y `.env.example`: los usa
`02_docker_con_una_app`.
